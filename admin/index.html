CATÁLOGO

Adicionar produto

Preencha os dados abaixo. Campos com * são obrigatórios.

01Identificação do produto

Dados que ajudam o cliente a encontrar o produto.

Separe por vírgulas. Ex.: Inverter, 12.000 BTU, 220 V.
Código interno de identificação. Ex.: GF-001.
02Preço e publicação

Defina a oferta e a visibilidade no catálogo.

Preencha se houver desconto, com um valor maior que o preço atual.
O botão Comprar no Mercado Livre abrirá este link em uma nova aba.
Ativo: aparece no catálogo. Inativo: fica oculto do site.
03Imagem do produto

Defina a imagem principal e adicione outras fotos para a galeria.

JPEG, PNG ou WebP, até 5 MB. O arquivo enviado tem prioridade sobre o endereço da imagem.
Use uma URL completa ou um caminho como assets/produtos/produto.webp.
Selecione várias fotos de uma vez. Até 11 imagens extras, com 5 MB cada.
Informe um endereço por linha. As fotos aparecerão na galeria da página do produto.
Confira os dados antes de salvar.
